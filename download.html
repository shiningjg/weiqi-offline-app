单机围棋

Android 离线安装包 · 适配 Android 16 · 断网也能玩
文件名 weiqi.apk · 约 26 KB · 兼容 Android 5.0 ~ 16

方式一：手机端直接装（vivo/iQOO 需先放行）

① 进入 设置 → 安全 → 更多安全设置（或「安装与验证」），关闭 「禁止安装恶意应用 / 纯净模式 / 安装监控」 的拦截开关。
② 进入 设置 → 应用与权限 → 权限管理 → 安装未知应用，找到你用来下载的浏览器，开启 「允许安装未知应用」。
③ 点上方按钮下载 weiqi.apk，用「文件管理 / 下载」打开，点击安装，弹窗点 「仍要安装 / 继续」。

方式二：用 ADB 安装（绕过 vivo 商店层拦截，最稳）

  1. 手机：设置 → 关于手机 → 连点「软件版本号」7 次开启开发者选项。
  2. 开发者选项里打开 USB 调试，用数据线连电脑。
  3. 电脑装好手机驱动后，终端执行：adb install weiqi.apk
  4. 看到 Success 即装好，桌面出现「单机围棋」。

ADB 走系统级安装，不经过 vivo 应用商店/纯净模式，能避开绝大多数侧载拦截。

关于这个 App

这是把整个围棋应用打进安装包的原生 Android App（WebView 离线壳），内置 9/13/19 路棋盘、双人对弈、人机对战（入门/普通/进阶）、提子、打劫、中国规则数子、悔棋、停一手、形势判断与 SGF 棋谱导入导出，并含详细玩法说明。所有运算在本地完成，安装后断网可永久使用。
